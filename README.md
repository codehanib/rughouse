# rughouse
# 파일럿 프로젝트
Spring Boot를 이용한 개인 파일럿 프로젝트입니다.

## 프로젝트 소개
회원의 상품 목록 확인, 회원 정보 수정 등의 기능과
관리자의 회원 관리 및 상품 관리 기능을 제공하는 온라인 쇼핑 웹사이트 입니다.

## 개발 환경
- Java
- Spring Boot
- Spring MVC
- MyBatis
- MySQL
- HTML / CSS / JavaScript
- Eclipse STS
- GitHub

## 주요 기능
### 회원
- 회원 가입
- 로그인
- 회원 정보 수정
- 회원 탈퇴

### 관리자
- 상품 등록, 수정, 삭제
- 회원 정보 조회, 삭제
